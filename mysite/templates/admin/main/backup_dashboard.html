Команды для сервера и автоматического деплоя (CLI)

Используйте эти команды в SSH терминале хостинга (Timeweb) или в скриптах CI/CD

Создание полного бэкапа (БД + фото):

python manage.py backup_data Сохраняет в mysite/backups/backup_sibsir_all_YYYYMMDD_HHMMSS.zip

Только каталог товаров с картинками:

python manage.py backup_data -i catalog Идеально для быстрой выгрузки актуального ассортимента

Восстановление последнего бэкапа на сервере:

python manage.py restore_data --yes Автоматически находит самый свежий архив и накатывает данные и фото

Чистый деплой с очисткой таблиц:

python manage.py restore_data backup_sibsir_all_xxxx.zip --clear --yes Полностью очищает старые записи и накатывает свежий каталог без конфликтов ID
